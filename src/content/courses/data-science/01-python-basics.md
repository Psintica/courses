## Quiz
**What is the difference between lists and tuples?**
- **Lists**: Mutable (can change), slower, `[1, 2, 3]`
- **Tuples**: Immutable (cannot change), faster, `(1, 2, 3)`

**Is Python case-sensitive?**
Yes.
